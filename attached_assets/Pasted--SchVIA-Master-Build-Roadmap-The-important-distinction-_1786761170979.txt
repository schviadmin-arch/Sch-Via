# PHASE 7 — OFFLINE-FIRST HARDENING

**Very important for your target market.**

We don't just put an "offline" badge on it.

We test:

```text
Internet ON
    ↓
Teacher takes attendance
    ↓
Internet disappears
    ↓
Teacher continues working
    ↓
Data safely stored locally
    ↓
Internet returns
    ↓
Sync
    ↓
Server confirms
```

Then test:

* duplicate sync
* conflicting edits
* interrupted sync
* device refresh
* browser restart
* multiple devices
* poor network
* long offline periods

This needs to be **genuinely reliable**, especially for schools with weak connectivity.
